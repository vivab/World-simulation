# WorldSimulation — Рождение мира (Alpha 0.2)

Мобильная 2D-песочница с живым процедурным миром. HTML5 Canvas + vanilla JavaScript; без тяжёлых библиотек, сервера, сборки и внешних ассетов.

## Что нового в Alpha 0.2
- Камера плавно следует за перетаскиванием; после отпускания пальца есть короткое инерционное скольжение.
- Плавный зум щипком на телефоне и колесом мыши; масштабирование привязано к месту жеста.
- Сила «Дождь» создаёт локальную погодную анимацию на 10 секунд: капли, брызги и расходящиеся круги, полупрозрачная туча с плавным затуханием.
- На телефонах панель инструментов можно прокручивать горизонтально, кнопки стали крупнее, а нажатия — мягче.
- Существующие сохранения Alpha 0.1 остаются совместимыми.

## Возможности первой версии
- Каждый новый мир генерируется из случайного seed: океан, острова, леса, пляжи, пустыни, горы, снег, реки.
- Три стартовых народа, города, жители, рост населения, запасы еды и основание новых поселений.
- Силы создателя: новое поселение, лес, дождь, метеорит, осмотр клетки или города.
- Мобильные жесты: перемещение одним пальцем, приближение двумя. На компьютере — мышь и колесо.
- Пауза и скорость 1×/2×/4×, миникарта и статистика.
- Сохранение мира в localStorage этого браузера (не синхронизируется между устройствами).

## Запуск
Откройте `index.html` в браузере или разместите файлы на GitHub Pages. Никакой `npm install` не нужен.

> Важное ограничение: это игровая **альфа-симуляция**, не законченный WorldBox. У городов простая экономика, а жители пока блуждают возле своего поселения; войны, дипломатия, полноценный поиск пути, сложное строительство и многотысячный ИИ запланированы на следующие этапы.

## Далее
1. Экономика поселений, профессии и дороги.
2. Территории, дипломатия, войны и армии.
3. Редактор генерации мира, сохранения с несколькими слотами.
4. Настоящие ресурсы, фермы, животные, корабли.

Сделано с приоритетом производительности для мобильных браузеров: карта заранее рисуется в буфер, симуляция обновляется отдельно от 2D-рендеринга.
